# C++ Modules - 42 Cursus

Brief summary of the concepts covered in each module:

* **c++_00**: Basic C++ concepts, classes, methods, I/O streams, and initial syntax (PhoneBook project).
* **c++_01**: Memory management, dynamic allocation (`new`/`delete`), pointers to members, and references.
* **c++_02**: Ad-hoc polymorphism, operator overloading, and the Orthodox Canonical class form.
* **c++_03**: Simple and multiple inheritance between classes.
* **c++_04**: Subtype polymorphism, abstract classes, and interfaces.
